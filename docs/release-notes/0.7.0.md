**What's new**
- **SubieScope for Windows (experimental).** There is now a version for Windows 10 and 11, with the same Dashboard, Logger, trouble codes, troubleshooting tests, dyno and ROM editor as on the Mac. It is brand new: so far it has only run against the built-in demo car, never on a real cable or car, so it may not work with yours yet. A cable or USB adapter shows up as a COM port, Bluetooth LE adapters do not work on Windows yet (pair the adapter in Windows and pick its COM port), and a Tactrix OpenPort is an experimental setting there. Reports on how it goes are very welcome.
- **The Tactrix OpenPort 2.0 is tested on a real car.** It ran on a 2009 WRX STI, with a replica of the cable, on a Mac: logging, trouble codes and reading the ROM all worked. So on a Mac it is no longer a setting: plug it in and press Connect. It is one car, so reports from other cars stay welcome. **Do you have a replica of the cable? Then never install Tactrix's official Windows driver or EcuFlash for it, and do not plug it into a PC that has them.** That software updates the cable's firmware, and that breaks a replica for good. SubieScope never changes the cable's firmware.
- **Logging over CAN with an OpenPort (experimental).** Subarus from about 2008 answer the same requests on the CAN bus, which is much faster: 50 to 66 samples per second on the test car, where the K-line gave 17 to 25. With an OpenPort connected there is a **K-line / CAN** switch in the connection box and in Settings. One catch, seen on that car: over CAN the ECU only gives the standard values and refuses the ECU specific ones, such as IAM and the knock corrections. SubieScope tells you which values were refused and keeps reading the rest. Switch back to K-line for those.
- **Freeze frame.** When the ECU stores a trouble code, it also saves what the engine was doing at that moment: rpm, speed, load, temperatures and fuel trims. **Trouble Codes** now shows that with an OBD-II adapter or an OpenPort, and it is part of the report you save or share.
- **The ROM editor works like RomRaider now (Advanced mode).** The maps are in a tree by group, and each map opens as a colour-coded table, several at a time. Select cells and change them with fine and coarse steps, set a value, multiply, or just type. **Cells you changed are marked**, a Difference view shows by how much, and a Changes panel lists every change since you opened the ROM, with a button to put a cell, a map or everything back. **Compare** holds a second ROM next to yours, for example the original next to a tuned one, and shows which maps and cells differ. There is a 3D view of a map, undo and redo, and the trouble code switches are listed too (read only). It still never writes to the car.
- **Reading the ROM from the car worked on a real car (experimental).** The 2009 STI gave its 1 MB ROM in under a minute through an OpenPort, with every checksum right. When the ECU refuses because of an earlier try, SubieScope now tells you to wait ten seconds instead of showing a code.
- **ECU Info and the dyno know more cars.** ECU Info names the car, the calibration ID and the processor for over 300 ECU IDs. On the dyno you can pick your car from a list of 93 Subarus, and its weight, gear ratios and tyre size are filled in.
- **Fixes.** Reading trouble codes with the KKL cable could fail on a real car, because SubieScope asked for more at once than the ECU answers; it now asks in smaller steps, like FreeSSM does. Fast poll no longer asks for more values at once than the ECU can send. When another program is using the cable, SubieScope says so instead of just not connecting. In a ROM, maps with decimal numbers showed noise and maps with one row showed a single cell; both read correctly now.
- **For developers:** `subiescope-cli freeze` reads the freeze frame, `--can` talks to the ECU over an OpenPort's CAN side, and `probe` prints the ROM's processor and how it is read.

**Install:** on a Mac, download `SubieScope.dmg` below, open it and drag SubieScope to Applications (replace the old version if you have one). You need macOS 14 or newer, and a VAG KKL cable with an FTDI chip, a Tactrix OpenPort 2.0 or a Bluetooth 4.0 (BLE) ELM327 adapter.

**On Windows (experimental):** download `SubieScope-windows-x64.zip` below, unzip it and start `SubieScope.exe` in the folder (keep the folder together, the program needs the files next to it). It is not signed yet, so the first time Windows shows a "Windows protected your PC" box: choose **More info**, then **Run anyway**. You need Windows 10 or 11 (64-bit); on Windows 10 you may have to install Microsoft's free WebView2 runtime first.
