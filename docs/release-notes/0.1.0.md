The first public version of SubieScope: live data, logging, diagnostics and a virtual dyno for Subarus, on the Mac.

**What's in it**
- Dashboard with dial, digital, bar and graph gauges; drag to reorder, three sizes
- Logger with RomRaider's full parameter set, including ECU-specific extended parameters, and CSV logs in RomRaider format
- 16 guided troubleshooting tests with live coaching and plain-language results (O2 sensors, MAF, AVCS, fuel trims, knock, boost, catalyst, charging and more)
- Trouble codes with explanations, and clear memory
- Log playback on the gauges, with hover snapshots and zoom
- Virtual dyno with a verdict on whether each pull is good
- Cable Setup assistant and a demo car to try everything without a cable

**Install:** download `SubieScope.dmg` below, open it and drag SubieScope to Applications. You need macOS 14 or newer and a VAG KKL cable with an FTDI chip. On first launch SubieScope downloads RomRaider's parameter definitions (about 2 MB).

This is an early release, developed against a simulated 2008 JDM WRX STI. Please report how it works on your car: https://github.com/marvin-socialista/subiescope/issues
